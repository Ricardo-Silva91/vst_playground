Lo-Fi Chain
Dead tape off a dusty record.

Lizard Suite chains four lo-fi modules in one plugin: an old sampler, a chewed cassette, a murky basement and a worn record. Each module has an "off" setting that passes the signal through bit for bit, so you can use one stage or all four. You can try it in your browser below before you download it.

Signal Chain
Input› 01 Dust · sampler› 02 Chew · tape› 03 Murk · room› 04 Vinyl · record› Output

The order is fixed and runs on each channel. Dust degrades the signal like an old sampler. Chew makes the level sag like tape losing the head. Murk puts the result in a dark room. Vinyl lays a noise bed over everything, so the hiss and crackle stay clean and are not crushed or reverberated. Parameters apply once per audio block with no smoothing. Chew's dropouts hit both channels together. Vinyl's hiss is different on each channel, so it sounds stereo. The plugin adds no latency.

Chew never adds energy

Chew only reduces gain, so in the level plot the output dips under the input and never rises above it. On the loop you hear the level sag and recover.

On silence, Vinyl plays hiss, a 50 Hz rumble and crackle. Move Age from 0 to 100 % and the bed gets louder and the pops come more often.

The full chain

12-bit grit, a few tape dropouts, a dark basement, and an old record underneath.

The demo runs a JavaScript port of lizard_suite/Source/DSP/LizardDust.h, LizardChew.h, LizardMurk.h and LizardVinyl.h, plus the processor's per-channel wiring, in an AudioWorklet. It is not the compiled plugin. The port rounds to 32-bit float the same way the C++ does. It was checked against a native build of the same cores and wiring: 0 mismatches over 1,152,000 samples across 6 settings at 44.1 and 48 kHz, including a seed change partway through. The only difference is the last bit of tanh in Dust's Drive stage. That last bit depends on the platform's math library, so the compiled plugin can differ there too. As in the plugin, parameters apply once per 128-sample block with no smoothing. Source: lizard_suite on GitHub.

01 Dust · Sampler
Rate

Sample-and-hold rate reduction with no reconstruction filter, so images appear above half the rate. The default of 26,040 Hz is close to an SP-1200. At or above the host rate it has no effect.

Range: 1,000 → 48,000 Hz    Default: 26,040
Bits

Bit-depth crush with no dither. 12 is the classic sampler grain. Below 6 the quantiser steps become clearly audible.

Range: 2 → 16    Default: 12
Low-pass · Drive

An optional 1-pole low-pass after the crush, and tanh drive before it. Both are off by default, because much of an old sampler's sound comes from the filter it doesn't have.

Low-pass: 0 (off) → 20,000 Hz    Drive: 1 → 8, default 1
Mix

Dry/wet blend. 0 turns Dust off and passes the signal through bit for bit.

Range: 0 → 1    Default: 1
02 Chew · Tape
Rate

Average number of dropouts per second. Each one sags the level to a random depth, then recovers over about 50 ms, like tape losing contact with the head.

Range: 0 → 20 /s    Default: 3
Depth

How deep the worst sag can go. Chew only lowers the gain, so the output never gets louder than the input. 0 turns Chew off.

Range: 0 → 1    Default: 0.5
Smooth

Gain smoothing time. Short values give abrupt, choppy drops. Long values give a slow, seasick wobble.

Range: 1 → 50 ms    Default: 8
03 Murk · Room
Room

Tail length. A dark Schroeder-style reverb with 4 damped combs into 2 allpasses. Comb feedback goes from 0.70 to 0.98, so it stays stable even at max.

Range: 0 → 1    Default: 0.6
Damp

A low-pass inside the comb feedback. Higher values darken the tail, from basement to underwater.

Range: 0 → 1    Default: 0.5
Mix

Dry/wet blend. 0 turns Murk off.

Range: 0 → 1    Default: 0.3
04 Vinyl · Record
Age

How worn the record is. Older records have louder hiss, more 50 Hz turntable rumble, and more frequent, harder pops.

Range: 0 → 1    Default: 0.4
Amount

Level of the noise bed, which is added on top of the signal. 0 turns Vinyl off.

Range: 0 → 1    Default: 0.5
Seed

Chooses the noise pattern. The same seed always gives the same crackle, so a bounce sounds the same every time. Change it if a pop lands somewhere you don't want it.

Range: 1 → 999    Default: 1
Starting Points
Dead Tape

The full chain: 12-bit Dust with a 9 kHz low-pass and a little drive, a few dropouts, a dark room at 30 %, and a fairly worn record underneath.

Basement

Murk only. Long room, heavy damping, 55 % wet. Sounds like music coming down the stairs.

Chewed Cassette

Frequent, deep dropouts with a short smoothing time, over a 32 kHz, 12-bit Dust with a 7 kHz low-pass.

Old 78

Dust at 16 kHz and 10 bits with a 4.5 kHz low-pass, under a very old, loud record. Crackly and boxy.

Clean

Every module off, so the output is bit-identical to the input. Start here and bring in one stage at a time.

These are the starting points in the live demo above. They are suggestions for the plugin's knobs, not factory presets inside the plugin.

Use Cases
Sampled-from-vinyl drums

Put it on a clean drum bus with Dust at 12 bits and a low-pass around 9 kHz, Vinyl at a low Amount, and Chew and Murk off. The kit sounds lifted off a record into an old sampler, with the crackle sitting under it rather than on top.

Dust: 26 kHz / 12 bit / LP 9k · Vinyl: Age 0.5, Amount 0.3 · Chew & Murk: off
Worn tape keys

On Rhodes or pads, use Chew with a long Smooth for slow level sags, plus a little Murk. It sounds like a cassette that has been played too many times.

Chew: Rate 2–4 / Depth 0.6 / Smooth 25–40 ms · Murk Mix 0.2
Next-room playback

Use Murk only, with high Damp and Mix above 50 %, for a dark, muffled space. Automate Mix to move a part between the room and the front of the mix.

Murk: Room 0.85 / Damp 0.9 / Mix 0.55 · others off
Noise bed for a whole track

Put an instance on an empty aux with only Vinyl on. Vinyl plays even with no input, so you get a continuous record bed that you can fade with the track. Vinyl's hiss differs per channel, so the bed is stereo.

Vinyl only: Age to taste / Amount 1 · set the level with the fader
Tips and Workflow
▶

Off really means off. Dust Mix, Chew Depth, Murk Mix and Vinyl Amount at 0 each pass the signal through bit for bit. Turning a module off this way is the same as removing it.

▶

Set the Dust rate against your session rate. Dust's Rate only does anything below the host sample rate. At 44.1 kHz, anything from 44,100 Hz up is clean. The images Dust creates appear above half the Dust rate.

▶

Automate in steps, not sweeps. Parameters apply once per audio block with no smoothing, so that the off settings stay exactly dry. Fast automation of Dust Rate or Bits can step at the block rate. That suits lo-fi material, but avoid it on sustained notes.

▶

Change the Seed to move a pop. Vinyl's noise is deterministic. If a crackle lands on a vocal phrase in your bounce, try another seed rather than lowering Age.
